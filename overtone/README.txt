OVERTONE — upgraded build

Run it:
1. Extract the folder.
2. Open index.html in a modern browser.
3. For the sampled Studio instruments, an internet connection is required because the FluidR3 soundfont samples are loaded remotely.
4. The built-in Synth engine works without those samples.

What changed:
- Removed the old themed music codex and its dataset.
- Removed the old media-specific examples/references from theory, world-music, encyclopedia, audio labels and navigation.
- Reworked the alternate sound engine into a neutral built-in Synth mode.
- Added the Progression Sketchpad: four editable diatonic chord slots, major/minor modes, tempo control, looping, random variations and local save.
- Upgraded the home page with learning-path progress and ear-training best-streak feedback.
- Refined spacing, panels, responsive behavior and hierarchy.
- Fixed stale/inconsistent labels, including the ear-training drill count and hard-coded encyclopedia counts.

No backend is required for this build. Progress, streaks and the progression sketch are stored locally in the browser.
