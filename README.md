# Safi Solutions

Main website for **safisolutions.org** plus a few self-contained projects hosted beneath the same GitHub Pages site.

## Main site

- `index.html` — homepage structure/content
- `assets/css/base.css` — Safi brand, navigation, hero, particles and shared styles
- `assets/css/work.css` — portfolio, client work, Manifold, about and contact sections
- `assets/css/responsive.css` — mobile/tablet layouts
- `assets/js/site.js` — navigation, reveals, floating particles, plasma mesh and problem router
- `assets/images/` — homepage-specific visuals such as the Manifold prototype preview
- `images/profphoto.png` — founder photo
- `logo-mark.png`, `logo-lockup.png`, `logo.png` — Safi brand assets kept at root because the live site/social metadata already reference them there
- `CNAME` — GitHub Pages domain

## Self-contained projects

These folders are intentionally independent from the main homepage and can maintain their own HTML/CSS/JS structure:

- `overtone/` — interactive music education
- `vellum/` — interactive Bible reading/research desk
- `thetradeschool/` — field-first skilled-trades education

## Editing rule

Homepage work belongs in `index.html` or `assets/`. Do not mix homepage assets into the self-contained project folders unless that project itself is being changed.
